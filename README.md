# Zekai Lin Portfolio

React + Vite portfolio prepared for Cloudflare Pages.

## Cloudflare Pages settings

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Node.js version: `22`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
